Attention: retrieving a context for each output

A small weighted-sum example and the difference between attention and guaranteed alignment.

Yasaman Samiee · Updated September 17, 2026 · 1 min read

An encoder-decoder model can compress an input into a fixed representation. Attention gives the decoder another option: consult a weighted combination of input representations for each output step.

Scores become weights

A scoring function compares a decoder query with encoder states. Applying softmax across the input positions produces nonnegative weights that sum to one. The context is the weighted sum of the corresponding value vectors.

For values [1, 0] and [0, 2], weights of 0.25 and 0.75 produce context [0.25, 1.5]. These are illustrative vectors; their coordinates do not correspond to named meanings.

What the mechanism does not prove

A large weight tells us how this weighted combination was formed. It is not automatically a causal explanation of the final prediction. Other heads, layers, and residual paths can contribute.

Cross-attention over n input positions for m output positions uses n × m pairwise scores per head in the straightforward implementation. Full self-attention over n positions uses n². Those statements concern the score matrix; other computations and implementation choices also affect total cost.
