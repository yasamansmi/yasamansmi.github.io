DeepSeek-R1: what group-relative rewards change

Distinguishing R1-Zero, R1, and distilled models in the original research.

Yasaman Samiee · Updated September 17, 2026 · 2 min read

This note concerns the original DeepSeek-R1 research release, not a comparison of current model rankings. The useful question is how a learning signal can be formed without a separate learned value model.

Keep the model names separate

R1-Zero applied reinforcement learning without a preliminary supervised fine-tuning stage. R1 introduced cold-start data and a multistage training pipeline to address usability and reasoning. Distilled models were trained from generated reasoning data using Qwen and Llama base families. These are distinct training setups, as described in the official repository.

Compare responses to the same prompt

Group Relative Policy Optimization (GRPO) samples a group of outputs for one prompt and forms relative advantages from their rewards. In the original formulation, an output’s reward is centered by the group mean and scaled by the group standard deviation. The group provides the baseline rather than a separately learned critic.

As a toy example, rewards [0, 0, 1, 1] have mean 0.5 and population standard deviation 0.5, producing normalized values [−1, −1, +1, +1]. This shows the comparison; it is not a complete training implementation. Equal rewards provide no within-group ranking signal, and numerical handling of zero variance matters.

The reward still sets the target

A relative score cannot make a flawed reward trustworthy. A format checker can reward formatting while missing a wrong answer. KL regularization discourages departure from a reference policy, but does not guarantee prevention of reward hacking.

Method reference: DeepSeek-R1 paper. The arithmetic example is illustrative.
